# Local SEO & Meta Generator

An open-source utility tool designed to help developers, web agencies, and local businesses automate their technical SEO optimizations, schema markups, and metadata generation.

## Features
- Generates JSON-LD Local Business Schema markup.
- Creates optimized title and meta description tags.
- Simple CLI script for quick marketing task automation.

## Installation
Clone the repository and run it locally using Node.js:
\`\`\`bash
git clone https://github.com/suryavanshiking/local-seo-meta-generator.git
cd local-seo-meta-generator
\`\`\`
